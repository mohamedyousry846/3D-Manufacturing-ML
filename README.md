# 3D Manufacturing ML

Machine learning project focused on analyzing manufacturing and 3D-related data to predict process parameters using Python and scikit-learn.

## Project Overview

This project explores the application of machine learning to a real-world manufacturing use case. The goal is to analyze manufacturing data and develop regression models that can predict relevant process parameters.

The project combines data preprocessing, feature engineering, exploratory analysis, machine learning, and model evaluation.

## ML Workflow

1. Data preparation and cleaning
2. Exploratory data analysis
3. Feature engineering
4. Selection of relevant input features
5. Training regression models
6. Model evaluation and comparison
7. Analysis and interpretation of prediction results

## Models

The project explores several regression approaches, including:

- Linear Regression
- Ridge Regression
- Random Forest Regression
- XGBoost
